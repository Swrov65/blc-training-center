# BLC Starter Website + Admin Panel (Demo)

This is a responsive React/Vite starter for Bangla Lion Computer City & Training Center.

## Run locally
1. Install Node.js (18+ recommended).
2. Run `npm install`
3. Run `npm run dev`

## Important limitations
- This is a front-end demo/prototype only.
- Admission submissions and approve actions exist only in browser memory and are not saved to a server/database.
- No real admin authentication, student login, SMS OTP, payments, file uploads, role security, or server-side validation are implemented.
- Sample phone/email/course fee and sample applications must be replaced/verified.
- Do not publish as a production system or enter real students' personal data until a secure backend is added.
- Production architecture recommendation: Firebase Auth + Firestore + Storage + Cloud Functions, with restrictive Security Rules and server-side role checks; or a comparable secured backend.
